App shell and routes
Route map is in App.tsx
Protected pages: Dashboard, Tasks, Workout, Goals, Finance, Calendar, Settings
Standalone protected editor routes: Journal new/edit
Public pages: Login, Signup
Shared navigation/layout is in Layout.tsx
Dashboard
File: Dashboard.tsx
Tabs: none
Sections: gamification bar, top tasks preview, daily tracking card, daily note, water tracker, reminders preview, goals preview, streak summary
Tasks
File: Tasks.tsx
Tabs: Tasks, Reminders
Sections (Tasks tab): top control card, new task action, filter row (All/Today/Overdue + category), week/date navigator, 7-day strip, task list cards, empty state
Modals: create/edit task modal, delete confirm modal
Note: Reminders tab mounts the Reminders page component
Reminders
File: Reminders.tsx
Tabs: none
Sections: reminders header/actions, reminders list cards, expandable 30-day heatmap per reminder, frequency details
Modal: add/create reminder modal
Workout
File: Workout.tsx
Tabs: Today, Library, History, Analytics, PRs
Sections (Today): workout label, planned exercises, set logging rows, progress/completion, workout photos
Sections (Library): muscle-group filter pills, exercise cards, add/edit/delete custom exercises
Sections (History): past plans list
Sections (Analytics): volume and trend cards/charts
Sections (PRs): personal record list
Modals: plan workout modal, add/edit exercise modal
Goals
File: Goals.tsx
Tabs (inside selected goal): Logs, Notes, Cards
Sections (goals list view): header/actions, goal cards
Sections (Logs tab): date + minutes logging, logs list
Sections (Notes tab): add note action, notes list/edit
Sections (Cards tab): flashcard review session, confidence rating, card list
Modals: create goal, add note, add flashcard
Finance wrapper
File: Finance.tsx
Tabs: Expenses, Tracker
Sections: tab switcher container, embeds Expenses page and FinancialTracker page
Expenses
File: Expenses.tsx
Tabs: none
Sections: header/actions, month selector, show-all toggle, filters/search, KPI cards, category summary, daily grouped expense list
Actions: add expense, delete expense, export CSV
Financial Tracker
File: FinancialTracker.tsx
Tabs: rule tab set inside panel (investment, trading, mindset, lifestyle)
Sections: alerts area, header/config action, completion/streak/rule cards, bucket cards, expandable task checklist per bucket, monthly history chart
Modals/Panels: complete task modal, config panel, rules panel
Calendar View
File: CalendarView.tsx
Tabs: Calendar, Weekly Review, Journal
Sections (Calendar tab): month nav, 7-column calendar grid, selected-day details (tasks + reminders + other daily data)
Note: Weekly Review and Journal tabs render their full page components
Weekly Review
File: WeeklyReview.tsx
Tabs: none
Sections: weekly metric cards, reflection/wins/improvement/focus text areas, save action
Journal
File: Journal.tsx
Tabs: Entries, Memory Wall

Recommendation Scoring Logic (implement in private helper):

For each candidate (cook = recipe, buy = premade meal):

CostScore = 1.0 - (candidateCostInr / maxCostAmongCandidates) → normalized 0-1
TimeScore: if cook, timeScore = (userPreference.TimeAvailabilityMinutesPerDay >= template preparationTime) ? 1.0 : 0.3; if buy, timeScore = 1.0
AdherenceScore: query last 30 days fulfillment_log for similar timing+type combos; rate = completed/total or 0.5 default
IngredientAvailabilityScore: check if all ingredient_ids in template have at least 1 price row with is_available=true; score = availableCount / totalIngredients
BudgetAlignmentScore: if budget_strictness == "strict" → costInr <= (budgetPerWeek/7) ? 1.0 : 0.2; else 0.8 constant
FinalScore = (0.30 * costScore) + (0.25 * timeScore) + (0.20 * adherenceScore) + (0.15 * availabilityScore) + (0.10 * budgetScore)
